# Cha Ghor Journal (Next.js)

A small Next.js App Router blog used to demo the **Next.js** template on
[DeshVPS](https://deshvps.com) Apps. DeshVPS runs `npm run build` and
`npm start` on port 3000. Pages are rendered on the server for every request;
the footer line shows which server answered and when.

Run locally: `npm install && npm run dev`.
